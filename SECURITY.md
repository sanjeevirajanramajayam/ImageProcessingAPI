# Security Policy

## Supported Versions

We actively release security patches and updates for the following versions of ImageProcessingAPI:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The security of ImageProcessingAPI is taken seriously. If you discover a security vulnerability, please **do not open a public GitHub issue**. Instead, follow these steps:

1. **GitHub Private Vulnerability Reporting**:
   Submit a report via the [GitHub Security Advisory page](https://github.com/sanjeevirajanramajayam/ImageProcessingAPI/security/advisories/new).

2. **Email Disclosure**:
   Alternatively, contact the maintainer directly via email with details of the vulnerability, reproduction steps, and impact assessment.

### What to Include
- Detailed description of the vulnerability
- Steps to reproduce or proof-of-concept exploit script
- Affected endpoints, query parameters, or file upload vectors
- Proposed remediation (if available)

### Response SLA
- **Initial Acknowledgement**: Within 48 hours
- **Triage & Status Assessment**: Within 5 business days
- **Patch Release**: Typically deployed within 14 days of triage confirmation
